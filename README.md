# LLM-Assisted Analysis and Quality Assessment for Batch-Aware ML Experiment Results

## Overview
Project for STAT GR5293 GenAI Final Project.

This project investigates:
1. Cross-batch robustness in RNA-seq classification
2. Structured extraction of ML performance patterns
3. LLM-assisted interpretation of experimental outputs
4. Grounding evaluation for LLM-generated analyses

---

## Repository Structure

## Pipeline

Module 1 — Structured Summary Builder
Module 2 — Pattern Detection Engine
Module 3 — LLM Analysis + Grounding Checker
Module 4 — Demo Chatbot
