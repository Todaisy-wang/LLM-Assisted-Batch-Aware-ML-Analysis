# LLM-Assisted ML Result Analysis Demo

This is the hosted interactive demo for the LLM-assisted ML result analysis project. The app reads structured evidence generated by previous project modules and answers questions about classifier robustness, normalization stability, split trends, batch sensitivity, LLM grounding quality, and limitations.

The app uses the OpenAI API for answer generation when `OPENAI_API_KEY` is configured as a Hugging Face Space Secret. If `OPENAI_API_KEY` is unavailable or an API call fails, the app falls back to deterministic evidence-based template answers.

This is not a general-purpose chatbot. It is scoped to the project’s ML experiment results and LLM grounding analysis, and it answers only from the included structured evidence files.

## Example Questions

- Which classifier is most batch-sensitive?
- Which normalization method appears most stable?
- What happens when split changes from 50 to 100?
- What are the most robust classifier-normalization combinations?
- Is the LLM-generated interpretation consistent with the observed evidence?
- What are the main limitations of this experiment?

## API Setup

For API-generated answers, add `OPENAI_API_KEY` as a Hugging Face Space Secret. Do not place the key in this repository.

Without the secret, the demo remains usable through deterministic template fallback answers.
